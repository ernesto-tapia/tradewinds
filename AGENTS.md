# Caribbean Tradewinds prototype rules

- Keep the game a small Godot 4.5.1 2D demo; implement only the current story.
- Every missing visual asset is a plain rectangle with a text label inside it, for example Ship, Ocean, Island, or Port.
- Use built-in fonts and flat colors. Do not create or download images, sprites, textures, icons, SVGs, complex artwork, 3D models, shaders, animation assets, or audio.
- Explicit exclusions such as final art, multiplayer, and full world simulation are not acceptance gaps.
- Record actual command results. Described tool calls and self-reported success are not execution evidence.
- Human merges PRs. Never merge automatically or mark an unmerged story Done.
