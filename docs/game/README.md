# Caribbean Tradewinds

## Project Setup

1. Open the project in Godot 4.5.1.
2. Run the scene to see the map placeholder and title.

## Windows Export

1. Go to the export tab in the editor.
2. Select the 'Windows Desktop' preset.
3. Click 'Export' to create the executable at `../build/CaribbeanTradewinds.exe`.

## Prerequisites for Exporting from a Clean Checkout

1. Install the matching Godot 4.5.1 export templates.
2. Create the build directory at `../build/CaribbeanTradewinds.exe`.
